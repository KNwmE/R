# Project instructions

## Design skills (always use when relevant)

This repo ships design skills in `.claude/skills/`. Invoke them automatically, without being asked, whenever a task matches:

- **ui-ux-pro-max**: use for ANY task that changes how something looks, feels, moves, or is interacted with: pages, components, layouts, color, typography, spacing, accessibility, animation, charts, responsive behavior, or UI reviews. Load it before writing UI code.
- **ui-styling**: Tailwind CSS / shadcn/ui component work and theming.
- **design-system**: design tokens, CSS variables, component specs.
- **design**: logos, icons, brand identity, mockups, social images.
- **brand**: brand voice, style guides, brand-consistent content.
- **banner-design**: banners for social, ads, website heroes, print.
- **slides**: HTML presentations.

When more than one applies, start with `ui-ux-pro-max`, then the more specific skill.
Skip these for pure backend, database, infrastructure, or non-visual work.
